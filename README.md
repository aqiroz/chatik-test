# Банальный чат (из коробки)

Простой чат на Node.js + WebSocket:
- несколько клиентов одновременно;
- установка никнейма;
- системные уведомления о входе/выходе;
- счётчик онлайн-пользователей.

## Быстрый старт

```bash
npm install
npm start
```

После запуска открой в браузере:

- локально: `http://localhost:3000`
- с другого компьютера в той же сети: `http://<IP_этого_компьютера>:3000`

> Чтобы узнать IP в Linux/macOS: `hostname -I` или `ip a`

## Как пользоваться

1. Открой страницу чата.
2. Введи ник и нажми **Сохранить ник**.
3. Пиши сообщения.
4. Открой ту же страницу на другом компьютере/вкладке — сообщения будут общими.

## Переменные окружения

- `PORT` — порт сервера (по умолчанию `3000`).

Пример:

```bash
PORT=8080 npm start
```
